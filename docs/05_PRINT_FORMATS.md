## Overview

This app ships a complete suite of custom print formats deployed via Frappe fixtures. They are automatically installed on `bench migrate` and synced on every deployment.

| Print Format | DocType | Copies |
|---|---|---|
| `GST Invoice - Original for Receiver` | Sales Invoice | Customer copy |
| `GST Invoice - Duplicate for Transporter` | Sales Invoice | Transporter copy |
| `GST Invoice - Triplicate for Supplier` | Sales Invoice | Company copy |
| `GST Purchase Order` | Purchase Order | Supplier copy |
| `Delivery Note - Original for Consignee` | Delivery Note | Customer copy |
| `Delivery Note - Duplicate for Transporter` | Delivery Note | Transporter copy |
| `Delivery Note - Triplicate for Supplier` | Delivery Note | Company archive |
| `Carton Shipping Label (4x6)` | Packing Slip | 4×6 thermal label |
| `Shipping Package Label (4x6)` | Packing Slip | 4×6 thermal label |

## GST Sales Invoice Print Formats

### Available Copies
- **Original for Receiver** — customer-facing copy
- **Duplicate for Transporter** — handed to the transporter/courier
- **Triplicate for Supplier** — company's file copy

### Layout Architecture

```
┌──────────────────────────────────────────────────────────┐
│  Company Logo + GSTIN  │  TAX INVOICE  │  Company Details│
│                        │  (title)      │  Address        │
├──────────────────────────────────────────────────────────┤
│  Payment Note (NEFT/RTGS instruction)                    │
├──────────────────────────────────────────────────────────┤
│  Bill To (Customer)  │  Invoice Details │  Payment Status │
│  Address + GSTIN     │  No, Date, Time  │  Paid ✓ / QR   │
├──────────────────────────────────────────────────────────┤
│  Items Table: Batch No | Item | Qty | Rate | Disc% | Amt │
├──────────────────────────────────────────────────────────┤
│  Shipping/Logistics     │  Net Total                      │
│  Details                │  + GST rows                     │
│                         │  Grand Total                    │
├──────────────────────────────────────────────────────────┤
│  GST Tax Breakup: Description | Rate | Taxable | Amount  │
├──────────────────────────────────────────────────────────┤
│  Generated By: [User] | Generated On: [Date]             │
│  Computer-generated — no signature required              │
└──────────────────────────────────────────────────────────┘
```

### Key Features
- **UPI QR Code**: Auto-generated from the Company's UPI ID (set in Company → Bank Details for Printing). Only visible when `outstanding_amount > 0`.
- **POS Detection**: When `is_pos = 1` or `is_consolidated = 1`, Shipping & Logistics section switches to "Over-the-Counter / Point of Sale (POS)" mode.
- **Transporter Detection**: When `transporter` is set on the invoice, the shipping section shows transporter name and booking hub.
- **Discount on Grand Total**: When `apply_discount_on = "Grand Total"`, the discount line renders *after* taxes (correct position per GST accounting rules).

### Required Setup for UPI QR
1. Go to **Accounts → Company** → open your company.
2. Find the **Bank Details for Printing** child table.
3. Add a row: `Print Label = "UPI ID"`, `Print Value = "yourcompany@upi"`.
4. The QR automatically appears on all unpaid invoices.

## GST Purchase Order Print Format

### Layout Architecture

```
┌──────────────────────────────────────────────────────────┐
│  Company Logo + GSTIN  │  PURCHASE ORDER  │  Company     │
│  Place of Supply       │  (title)         │  Address     │
├──────────────────────────────────────────────────────────┤
│  Supplier Details     │  Order Details    │  Ship To     │
│  Name, Address,       │  PO No, Date,    │  Company +   │
│  GSTIN, Phone         │  Required By     │  Warehouse   │
├──────────────────────────────────────────────────────────┤
│  Items Table: Item | Qty | List Rate | Discount% | Amount│
├──────────────────────────────────────────────────────────┤
│  Terms & Conditions   │  Net Total + GST + Grand Total   │
├──────────────────────────────────────────────────────────┤
│  GST Tax Breakup: Description | Rate | Taxable | Amount  │
├──────────────────────────────────────────────────────────┤
│  Generated By: [User] | Generated On: [Date]             │
└──────────────────────────────────────────────────────────┘
```

### "Ship To" Column — Warehouse Address
The **Ship To** column renders the Warehouse shipping address. For this to work correctly:
1. Create an `Address` record (Contacts → Address → New).
2. Set **Address Type** to `Shipping`.
3. In the **Links** table, link it to your **Warehouse**.
4. The PO's `shipping_address_display` will automatically resolve to this address when the `set_warehouse` is set on the PO.

### Selecting the Print Format
1. Open a Purchase Order.
2. Click the **Print** icon (top-right).
3. In the Print Format dropdown, select `GST Purchase Order`.

## Delivery Note Print Formats

### Available Copies
- **Original for Consignee** — customer-facing copy
- **Duplicate for Transporter** — transporter's copy
- **Triplicate for Supplier** — company's file copy

### Layout Architecture

```
┌──────────────────────────────────────────────────────────┐
│  DELIVERY NOTE        │  [ORIGINAL FOR CONSIGNEE]        │
│  [Delivery note no.]  │  Date: [Date]                    │
├──────────────┬─────────────────┬───────────────────────  │
│  CONSIGNOR   │    CONSIGNEE    │  DELIVERY & LOGISTICS   │
│  (Warehouse) │  (Customer)     │  Transporter, LR No,   │
│  Name, Addr  │  Ship Addr,     │  Vehicle No, Box Count │
│  Phone       │  GSTIN          │                        │
├──────────────┴─────────────────┴────────────────────────┤
│  Items Table                                             │
│  Item Name | Qty | UOM | Allocated Boxes (Packing Slips)│
├──────────────────────────────────────────────────────────┤
│  RECEIVER'S STAMP &  │  AUTHORISED SIGNATORY            │
│  SIGNATURE           │  (Company)                        │
└──────────────────────────────────────────────────────────┘
```

### Key Features
- **Consignor (Warehouse) Address**: Renders the Warehouse name and linked warehouse address. Falls back to Company shipping/dispatch address.
- **Consignee (Customer) Address**: Renders the Shipping Address (`shipping_address_name`). Falls back to billing address if no separate shipping address.
- **Packing Slip IDs on Items**: The items table shows which box (`Box #1`, `Box #2`) each item was packed into, with the Packing Slip ID.
- **No Financial Data**: Rates and values are intentionally omitted — this is a goods receipt document only.
- **Godown Delivery Banner**: If `custom_is_godown_delivery = 1`, the Consignee section shows a godown pickup box with the transporter's godown destination address.

## Carton Shipping Label (4×6 Thermal)

**DocType**: Packing Slip  
**Label Size**: 4 inches × 6 inches (standard thermal label)

### Layout Architecture

```
┌────────────────────────┬────────────────┐
│  PACKING SLIP #        │  BOX NUMBER /  │
│  [Barcode]             │  TOTAL         │
│  DELIVERY NOTE #       │  BOX [X]       │
│  [Barcode]             │  OF [Y]        │
│  Date: [Date]          │                │
├────────────────────────┴────────────────┤
│  CONSIGNEE (CUSTOMER)       [DOOR/GODOWN│
│  [Customer Name]             DELIVERY]  │
│  [Delivery Address]                     │
│  GSTIN: [GSTIN]                         │
├─────────────────────────────────────────┤
│  SHIPPING & ROUTING DETAILS │ [Routing  │
│  Transporter: [Name]        │  Code Box]│
│  Booking Hub: [Address]     │           │
│  Customer PO Ref: [PO No]   │           │
├─────────────────────────────────────────┤
│  CONSIGNOR (SENDER)                     │
│  [Company Name]                         │
│  [Company Address] | GSTIN: [GSTIN]     │
└─────────────────────────────────────────┘
```

### Anti-Pilferage Design
Product names and quantities are **intentionally omitted** from the outer carton label. Only logistics routing information is printed. This prevents pilferage of high-value goods during 3PL transit.

### Printing Labels
1. From a Delivery Note, click **Packing Slips → Manage / Edit**.
2. To print a single label: click the **Print** icon on a specific row.
3. To print all labels: click **Print All Slips** (footer button) — generates a continuous multi-page print stream.

## Deploying / Updating Print Formats

Print formats are managed as **Frappe Fixtures** and versioned in Git.

### After Making UI Changes to a Print Format
```bash
# Export updated fixtures
bench --site zap.localhost export-fixtures --app core_customizations
git add core_customizations/fixtures/print_format.json
git commit -m "fix: update GST Invoice print format"
```

### Deploying to Production
```bash
# On the production server:
bench --site your-site.com migrate
# migrate automatically imports all fixtures including updated print formats
```

### Checking Sync Status
The `after_migrate.py` hook verifies all required print formats exist after every migration. Check the site logs if a format is missing:
```bash
bench --site zap.localhost run-tests --module core_customizations.tests.test_setup_permissions
```

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| Print format not appearing in dropdown | Module filter mismatch | Check that `module = "Core Customizations"` in the fixture |
| UPI QR not showing | Outstanding amount = 0 or UPI ID not set | Add UPI ID in Company → Bank Details for Printing |
| Warehouse address not in PO "Ship To" | No Address linked to Warehouse | Create an Address record linked to the Warehouse (Contacts → Address) |
| Packing slip IDs not showing on DN print | Packing slips are Draft (not submitted) | Submit packing slips first; Draft slips are excluded from print |
| Old/deleted format still showing | Frappe cached print format list | Clear cache: `bench --site ... clear-cache` |
